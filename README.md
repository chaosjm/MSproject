# MSproject

This report aims to find new correlations using four classifier models: K-Nearest Neighbors (KNN), K-means, random forest and Support Vector Machine (SVM); and the feature reduction model T-distributed Stochastic Neighbor Embedding (t-SNE).

Based on the data set obtained from the publication:

Fitzgerald KC, Smith MD, Kim S, Sotirchos ES, Kornberg MD, Douglas M, Nourbakhsh B, Graves J, Rattan R, Poisson L, Cerghet M, Mowry EM, Waubant E, Giri S, Calabresi PA, Bhargava P. Multi-omic evaluation of metabolic alterations in multiple sclerosis identifies shifts in aromatic amino acid metabolism. Cell Rep Med. 2021 Oct 19;2(10):100424. doi: 10.1016/j.xcrm.2021.100424. PMID: 34755135; PMCID: PMC8561319.

Requires the packages: caret, tidymodels, vip, dplyr, mlbench,tidyverse, cluster, factoextra, Rtsne, kernlab, adabag.

Recommendation: Run with Rstudio
